# 海啸启发的长波建模项目：最终交付说明

作者：JIajun FU。版本：V1.0，2026 年 10 月。

本项目已经完成一个明确范围内的研究型计算项目闭环：模型推导、求解器实现、独立参考验证、参数实验、网格敏感性检查、真实实验数据的条件性比较，以及报告和可复现交付。最终英文报告是 research-style project report，并非已发表论文。

## 研究问题与模型

研究问题是：波从深水传播到浅水时，线性与非线性浅水模型的预测如何变化？如何判断两种预测的差异超过数值离散的影响？

模型使用一维、静态海床、全湿区域的浅水方程。令 h=η−b、q=hu，则质量方程为 h_t+q_x=0，动量方程为 q_t+(q²/h+gh²/2)_x=−gh b_x。围绕静水深 D=−b 线性化，得到 η_t+(Du)_x=0、u_t+gη_x=0。报告完整给出推导、数值通量、海床源项平衡和边界条件。

代码包含一阶基线、平底线性/非线性求解器、变水深 MUSCL+SSP-RK2 求解器，以及用于对齐突变海床的亚临界 Bernoulli 界面耦合。后者假设无水头损失，不能当作一般临界流、共振流或实际能量耗散模型。

## 已完成的主要结果

**1. 数值验证：35 项测试全部通过。**

测试覆盖静水保持、解析行波、制造解、质量收支、时间步 CFL、入射边界、反射墙和突变海床耦合。它们提供算法实现的证据，不等于真实海啸全流程验证。

**2. 突变海床：静水保持并不自动保证正确的行波传输。**

20 m→5 m 水深的线性解析反射系数为 1/3，透射系数为 4/3。在 4,000 格，线性模型相对解析解的 L2 差异为约 0.368%；低幅非线性 Bernoulli 耦合相对该线性参考的差异约 0.792%。非线性差异包含物理与数值影响，不能全部解释为离散误差。原 hydrostatic 控制算法虽保持静水，其行波结果仍存在约 16.45% 的差异，因而被保留为对照，而不用于该步阶研究的主结论。

**3. 平滑陆架：18 个场景与网格筛查。**

水深比为 0.5/0.25，过渡宽度为 200/800/2400 m，初始相对幅度 A/D 为 0.001/0.01/0.05。每个场景比较线性与非线性模型，并使用 1000、2000、4000 格。

定义 E 为两模型最终表面波形的相对 L2 差异，S 为两模型网格变化的合计代理量。采用经验阈值 E/S≥5。标准网格下 12/18 场景通过。对两个宽过渡、弱幅场景追加到 16,000 格后，两者也通过，E/S 分别约为 14.64 和 19.10。该追加选择是探索性后续实验。其余四个弱幅场景仍标记为“当前网格下未解析”，没有将其差异宣称为已确认物理效应。

E 超过 100% 并不意味着每一点波高都错了 100%；局部波包的相位和形状变化也会造成较大的整体 L2 差异。Green 定律仅用作慢变水深参考，不是所有几何的精确解。

**4. NOAA 实验比较：无调参、无拟合时间平移。**

使用官方 Case A 的 G4 记录作为入射输入，比较下游 G5–G10 六个测点。每个测点仅扣除前 20 个采样的均值。固定时间窗为原记录的 265.05–283.00 s，共 360 个采样；使用 400、800、1600 格。

在 1600 格，按各测点观测绝对峰值归一化的 RMSE：线性模型为 4.06–9.64%，非线性模型为 3.96–10.17%。非线性模型没有在每个测点都更好。

官方网页与归档文件对 G4 位置及名义幅深比存在不一致。本项目采用与实际记录配套的归档坐标 G4=12.64 m，并公开该选择。右端使用全湿截断反射墙，非湿干岸线。因此这部分严格称为“条件性实验比较”，不宣称完成官方溯上 benchmark 或历史海啸事件验证。

## 复现

使用 Python 3.11，在解压后的项目根目录：

```bash
python -m pip install -r requirements.txt
python scripts/run_verification.py
python scripts/reproduce_all.py
```

完整复现时需要联网下载官方实验归档；脚本会验证 SHA-256。第三方原始测量数据未随项目分发。只做合成场景时运行：

```bash
python scripts/reproduce_all.py --synthetic-only
```

可选安装 `requirements-notebooks.txt` 后运行 Jupyter。交互 HTML、GIF、PDF 和 notebook HTML 阅读版无需重新计算即可查看。绘图与动画的演示网格是 1000 格，定量研究结论以结果 CSV 中的相应精细网格为准。
